#  Python Data Science Handbook

A practical, beginner-friendly journey through **Python for Data Science**, from NumPy and Pandas to Data Visualization, Machine Learning, and Deep Learning.

This repository contains structured **Jupyter Notebooks, notes, examples, and practical exercises** designed to build a strong foundation in the Python Data Science ecosystem.

---

##  What You'll Learn

-  Python fundamentals for Data Science
-  NumPy — numerical computing
-  Pandas — data manipulation and analysis
-  Data Visualization
-  Exploratory Data Analysis
-  Machine Learning
-  Deep Learning with PyTorch
-  Deep Learning with TensorFlow

##  Learning Roadmap

### 1.  NumPy

Learn the fundamentals of numerical computing with Python.

Topics include:

- Arrays
- Array creation
- Indexing and slicing
- Mathematical operations
- Broadcasting
- Aggregation
- Random numbers
- Linear algebra basics

 **Notebook:** `01_NumPy.ipynb`

---

### 2.  Pandas

Learn how to work with structured datasets.

Topics include:

- Series and DataFrames
- Loading datasets
- Selecting and filtering data
- Handling missing values
- Sorting
- Grouping and aggregation
- Merging and joining
- Data cleaning

 **Notebook:** `02_Pandas.ipynb`

---

### 3.  Data Visualization

Turn data into meaningful visual insights.

Topics include:

- Matplotlib
- Seaborn
- Line plots
- Bar charts
- Histograms
- Scatter plots
- Distribution plots
- Correlation visualization

 **Notebook:** `03_Data_Visualization.ipynb`

---

### 4.  Data Analysis

Learn how to explore and understand real-world datasets.

Topics include:

- Exploratory Data Analysis (EDA)
- Data cleaning
- Statistical summaries
- Feature relationships

- Drawing insights from data

 **Notebook:** `04_Data_Analysis.ipynb`

### 5.  Machine Learning

Build your first machine learning models.

- Machine Learning fundamentals

##  Installation

Clone the repository:

```bash
git clone https://github.com/Riktam45/Python-DataScience-Handbook.git
```

Move into the project:

```bash
cd Python-DataScience-Handbook
```

Create a virtual environment:

### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

### macOS / Linux

```bash
python3 -m venv venv
source venv/bin/activate
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

---

##  Running the Notebooks

Start Jupyter Notebook:

```bash
jupyter notebook
```

Or use JupyterLab:

```bash
jupyter lab
```

Then open the `notebooks/` directory and follow the notebooks in order.
