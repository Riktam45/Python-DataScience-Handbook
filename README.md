# Notebook Collection

These notebooks are the practical, executable companion to the Python Data Science Handbook.

## Notebooks

1. `01_NumPy.ipynb` — numerical computing and arrays
2. `02_Pandas.ipynb` — data manipulation and analysis
3. `03_Data_Visualization.ipynb` — Matplotlib and Seaborn
4. `04_Data_Analysis.ipynb` — analysis workflow, preprocessing and outliers
5. `05_Machine_Learning.ipynb` — Scikit-learn workflow
6. `06_Deep_Learning_PyTorch.ipynb` — PyTorch neural-network workflow
7. `07_Deep_Learning_TensorFlow.ipynb` — TensorFlow/Keras workflow

The notebooks use small, self-contained educational data rather than external Kaggle or dataset-platform downloads.

Note: examples from the Word handbook have been reorganized into notebook cells, and obvious Word-formatting artifacts have been normalized where necessary so that the practical examples are runnable.
